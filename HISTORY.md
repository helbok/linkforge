# Project timeline

A chronological summary of LinkForge's simulated two-year history, intended
as a study aid for understanding how a small project grows over time.

## 2020

- **January** — Project scaffolded; base-62 encoder added and tested.
- **February** — `ShortenerService` and in-memory storage; `IIdEncoder` extracted.
- **March–April** — Service tests; idempotent shortening; first CLI.
- **May** — Argument parser extracted and tested; command dispatch refactored.
- **June–July** — JSON file store (with atomic writes) and `UrlStoreFactory`.
- **August** — `.editorconfig`; README rewritten.
- **September–October** — URL validation, maximum length, custom codes.
- **November** — Encoder boundary tests; configuration centralised.

## 2021

- **January–February** — CI, coverage, .NET 5 upgrade, contributor docs.
- **March–April** — Link expiration, hit counts, async storage refactor.
- **May** — 1.0.0 released.
- **June–July** — Allocation-free encoder; file-store integration tests.
- **August** — SQLite backend; API reference and examples.
- **September** — Dependency injection; SQLite resource disposal.
- **October** — 1.1.0 released.
- **December** — Final documentation and timeline.
