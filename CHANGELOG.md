## [1.0.0] - 2021-05-19

### Added

- Base-62 short code encoding.
- In-memory and JSON-file storage backends.
- Command-line interface for shorten, resolve, and list.
- URL validation (http/https only, maximum length).
- Custom short codes.
- Link expiration (TTL) and hit counting.
- GitHub Actions CI with test coverage reporting.
